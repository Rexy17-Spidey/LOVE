## How It Works

1. Simply drop your photograph into the folder above using the indicated filename (e.g., save your photo as `assets/images/editorial/cover.jpg`).
2. Refresh the website in your browser. The site automatically detects and displays your photo!
3. If a photo hasn't been added yet, the website gracefully falls back to the custom-designed gilded emerald SVG placeholder with the frame's title and aspect ratio.
4. You can also edit any image path in `config.js` if you prefer different filenames or formats (e.g. `.png` or `.webp`).
